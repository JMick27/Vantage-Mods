# Vantage Unreal Runtime 0.1.0

This reviewed foundation defines the game-neutral Vantage engine-runtime ABI and
validates version-bound Unreal game-module contracts. Its capability mask is zero:
it does not hook games, render VR, modify cameras, provide input, or establish game
compatibility.

The release ZIP contains only the compiled Vantage-authored DLL, `runtime.json`,
and third-party notice. It contains no Unreal Engine SDK files, game code/assets,
UEVR, or UUVR.
